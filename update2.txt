## 새로운 설정
```
**Hide Hair**
- 공룡 변신 시 아바타 머리 숨김
**Hide Race Appearance**
- 다른 플레이어에게 종족 외형 숨김
-# 프로필과 견문색 각성에서는 보임
- 종족 채팅 꾸미기 효과도 숨김
### 모바일 UI (Modern Buttons)
**Select Mode**
- 스킬 선택 → 조준 후 사용
**Tap Mode**
- 클릭 시 스킬 즉시 사용 (자동 중앙 타겟팅)
```

## 밸런스 조정

**헌블**
```
Z 쿨타임 5초 → 8초
최대 견문 감소 횟수 1 → 3
X 쿨타임 8초 → 10초
```

**패시브 변경**
```
**베리어스**
- 기본 데미지 보너스 +5%
- 스턴 제거
```

## 패시브 밸런스 조정
```
드라코닉 / 나이트 / 파이로 / 볼트 5.5% → 30%

Healing Havoc
- 재생 지속시간: 1.5배 → 10배
- 힐 스킬 감소: 5배 → 10배
- 지속시간: 10초 → 45초

기타 패시브

Fearless
- 데미지: 5% → 10%

Pitiless 
- 데미지: 5% → 10%

Tempest 
- 발동 확률: 7.14% → 15%
- 데미지: 공격력의 20% → 40%

Dazzle
100% 확률 (쿨 8초) → 25% 확률 (쿨 10초)
```

## 밸런스 패치

**버프**
```
고무: 기어 4 각성 게이지 요구 제거
게일 피스트: 각성 게이지 요구 제거
새새 각성: 
- V 스킬 데미지 추가, 비행 개선
쿠릉 각성 개선: 충전 속도, 스턴, 데미지, 시전 속도
골드 스피어: Z 스킬 범위 2배 증가
모래: C 스킬 공중 사용 가능
빙빙 각성: C 스킬 공중 사용 가능
소울: 스킬 시전 속도 증가
배리어: 스킬 시전 속도 증가
불게검: X 스킬 무적 추가
```
**너프**
```
문문: 히트박스 및 쿨타임 조정
가스: V 스킬 데미지 / 지속시간 / 범위 감소
키오루 각성: 사거리 및 데미지 감소
밍크 3차 각성: 이동속도 25% 감소
천사 3차 각성: 힐 메커니즘 변경
노래: E 스킬 속도 20% 감소
어둠: Z 스킬 피격 시 캔슬 가능
여러 무기와 스킬에 견문 깎는 횟수 제한 추가
```
