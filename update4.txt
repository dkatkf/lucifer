# v10.0.5
## 변경 사항

```
열매 뽑기 시스템 개선
- View 버튼 추가
- 각 키 사용 시 획득할 열매 미리보기 가능
- 단일 / 10회 개봉 모두 적용
- 보상은 100% 고정되며, 키를 사용해 열매를 받을 때까지 변경되지 않음

도톰(Palm) X 스킬 데미지 25% 감소

3세계 제단에서 신화 열매 희생 시 쿨타임 감소 효과 상향
- 보스 등장 시간: 10분 → 7분
```

## 버그 수정

```
[수정] 아크로 대거 X 스킬 문제 수정
[수정] 서버 메뉴에서 현재 서버가 표시되지 않거나 일부 서버 검색이 되지 않던 문제 수정
[수정] 전투 중 새 검 획득 시 기존 검이 해제되던 문제 수정
[수정] 게 보스 관련 문제 수정
[수정] 선물 UI에서 **(DisplayName / @username)**이 서로 바뀌어 표시되던 문제 수정
[수정] 해골 해적 섬(2세계) 클릭이 되지 않던 문제 수정
[수정] 숲숲(변신) X 스킬 가시에 충돌 판정이 적용되던 문제 수정
```

해당 변경 사항은 v10.0.5 서버에 적용되었습니다.
